                        CC-WEB 客户端部署手册
================================================================================
版本：2026-09-29
适用对象：拿到 cc-web-dist 分发包的开发者（每台开发机各装一份）
================================================================================


【0】这套系统是什么（先理解拓扑，装起来才不迷糊）
--------------------------------------------------------------------------------
  你的电脑（每台开发机，本手册要装的东西都在这里）：
    - cc-web.exe        网页主程序。浏览器打开 localhost:3030 使用
    - java_compiler_mcp 编译 MCP。用你本机的 JDK 编译 Java、打补丁

  一台固定服务器（管理员维护，你不用装）：
    - patch_search      补丁中心后端（补丁库、账号、产品环境变量、问题解决账本）
    - 源码检索 MCP       只读检索标品源码

  一句话：客开代码在你本机，标品源码只有服务器一份 —— 所以这套东西必须装在
  “每一台”开发机上，不是装一台就够。


【1】分发包内容
--------------------------------------------------------------------------------
  cc-web-dist\
    ├── start.bat                    启动入口（必须用它启动，见【5】）
    ├── cc-web.exe                   主程序（页面与服务器地址已编译进 exe）
    ├── mcp-servers.json             MCP 注册配置（含服务器地址与 token，已配好，勿改）
    ├── claude-settings.example.json 模型凭证模板（见【4】，需要你填真实值）
    ├── 部署说明.md                   简版说明
    └── java_compiler_mcp\           编译 MCP（整个文件夹一起拷，别拆开）
        ├── java_compiler_mcp.exe
        └── _internal\               依赖全在这里，必须与 exe 同级

  把整个文件夹拷到本机任意目录即可：内部全部用相对路径互相引用，放在哪都能跑。


【2】每台机器必须先装的软件
--------------------------------------------------------------------------------
  1) Claude Code CLI
     - 安装后命令行能跑通：claude --version
     - 安装时务必加入 PATH（cc-web 靠 PATH 找它）

  2) Git for Windows
     - Claude Code 在 Windows 上依赖 Git Bash
     - 建议按默认路径安装（C:\Program Files\Git）；装到别处要设环境变量（见【7】）

  3) JDK（工程要求的版本，如 1.8）
     - 编译 Java 用。装哪都行，路径填到网页的「产品环境变量 → 本地jdk路径」（见【6】）

  4) Python 3（加入 PATH）
     - 只有「差异报告」功能需要（生成 HTML 对比报告）。不装则跳过差异报告，不影响其它功能

  5) Node.js（可选）
     - 只有「前端补丁构建」需要。纯后端场景可不装


【3】安装 skill（智能开发节点要用，必须装）
--------------------------------------------------------------------------------
  智能开发（问题解决）节点会调用两个 skill，必须装到“用户级 skill 目录”：
      C:\Users\<你的用户名>\.claude\skills\

  要装的 skill：
    - java-compiler-mcp ：编译/打补丁 MCP 的工具说明书（阶段一编译必用）
    - diff-report       ：生成 HTML 源码差异报告（阶段一/二生成对比报告用）

  安装步骤：
    1) 找管理员要两个 skill 包：java-compiler-mcp.zip、diff-report.zip
    2) 解压到 C:\Users\<你的用户名>\.claude\skills\
       解压后的目录结构必须是（SKILL.md 直接在该 skill 目录下，不要再套一层同名目录）：
         ...\.claude\skills\java-compiler-mcp\SKILL.md
         ...\.claude\skills\diff-report\SKILL.md
    3) 验证：在任意目录打开 claude，列出可用 skill，应能看到上面两个名字

  说明：
    - 不装 java-compiler-mcp → 阶段一无法编译/打补丁（会失败）
    - 不装 diff-report（或本机没有 python）→ 跳过差异报告生成，不影响补丁本身

  可选：FBIP 领域 skill 库
    - 如果管理员给了你一套 FBIP 领域 skill 库（目录里有 java-compiler-mcp、fbip-skill-router
      等），把它放到本机任意目录，然后在网页「产品环境变量 → 本机skill库」里填该目录的
      绝对路径。阶段一会按需去读里面的说明书（不填也能跑）。


【4】配置模型凭证（唯一必须手工配的一步）
--------------------------------------------------------------------------------
  把 claude-settings.example.json 复制到：
      C:\Users\<你的用户名>\.claude\settings.json
  （去掉 .example 后缀），然后填入真实的网关地址与 token。

  作用：
    - claude CLI 靠它连模型网关
    - cc-web 读它来生成界面上的「模型下拉」列表
  不配的后果：模型下拉是空的，程序会以 --model unknown 调用 claude 而失败。

  注意：该文件含密钥，不要外传、不要放进分发包。


【5】启动
--------------------------------------------------------------------------------
  双击 start.bat（不要直接双击 cc-web.exe）。

  为什么：start.bat 会先设置环境变量 CC_WEB_MCP_CONFIG，指向本文件夹的
  mcp-servers.json，保证 MCP 从本文件夹加载。直接双击 exe 会导致 MCP
  “静默不加载” —— 界面上完全看不出来，只在日志里留一行提示。

  启动后浏览器会自动打开 http://localhost:3030

  后台常驻（不弹浏览器）：先设环境变量 CC_WEB_NO_BROWSER=1，再启动 start.bat。

  日志位置：C:\Users\<用户名>\.cc-web\logs\cc-web-<日期>.log
  自检 MCP 是否加载：日志里应有类似一行 —— “已加载 2 个 MCP server（<路径>）”，
  且路径指向分发包里的 mcp-servers.json。


【6】网页端首次配置（产品环境变量）
--------------------------------------------------------------------------------
  登录后，进入「产品环境变量」页签，新增一条，字段说明：
    项目名称        ：随意起名
    产品 / 版本     ：从管理员预置的字典里选（如 FBIP 8.1）
    客开代码目录    ：本机客开工程根目录（绝对路径）
    home/war包地址  ：编译依赖根（工程 home / war 包地址）
    本地jdk路径     ：★必填★ 你本机 JDK 根目录（即 JAVA_HOME）
    本机skill库     ：FBIP 领域 skill 库根目录（可选，见【3】）
    数据库连接      ：可选；填了阶段一允许“只读”查询数据库
    远程调试地址    ：可选；填了阶段一允许“线程级”远程调试

  说明：这些都是“每台机器不一样”的东西（尤其 JDK 路径），所以放在这里按机器配置，
        不写进分发包。


【7】可选环境变量（遇到问题再设）
--------------------------------------------------------------------------------
  CC_WEB_NO_BROWSER=1            启动时不自动弹浏览器
  CLAUDE_CODE_GIT_BASH_PATH      Git 不在默认路径时，指定 ...\bin\bash.exe 绝对路径
  CLAUDE_CMD                     cc-web 找不到 claude 时，指定其绝对路径

  设置方式（PowerShell，永久，用户级）：
    [Environment]::SetEnvironmentVariable("CLAUDE_CODE_GIT_BASH_PATH","D:\Git\bin\bash.exe","User")


【8】自测清单（装完按顺序验一遍）
--------------------------------------------------------------------------------
  □ claude --version                能打印版本
  □ claude 简单提问一次              能正常回答（说明网关 / settings.json 配好了）
  □ 双击 start.bat                  浏览器打开 localhost:3030
  □ 登录                             能进主界面，模型下拉不是空的
  □ 看日志                           “已加载 2 个 MCP server”且路径是分发包那份
  □ 用「智能开发」跑一次小任务        编译类工具能用（说明 JDK + 编译 MCP + skill 都正常）


【9】故障排查
--------------------------------------------------------------------------------
  现象                              原因 / 处理
  --------------------------------  ------------------------------------------------
  编译类工具不可用                  没走 start.bat；或 java_compiler_mcp\_internal\ 不完整
  模型下拉是空的                    ~/.claude/settings.json 没放 / 格式不对（见【4】）
  发消息就报错                      该机 claude 单独跑不通；先在命令行验证 claude
  skill 找不到                      skill 没装到 ~/.claude\skills\，或 SKILL.md 多套了一层目录
  差异报告没生成                    本机没装 python，或没装 diff-report skill
  提示 3030 端口被占用              已有实例在运行
  Failed to load Python DLL         java_compiler_mcp.exe 与 _internal\ 被拆开了
  提示找不到 git-bash               Git 非默认安装路径，设 CLAUDE_CODE_GIT_BASH_PATH（见【7】）


【10】安全注意（务必看）
--------------------------------------------------------------------------------
  - cc-web 监听 0.0.0.0:3030，并以“完全放行权限（bypassPermissions）”调用 Claude。
    同一局域网内任何机器都能打开你电脑上的这个页面，并让 Claude 在你机器上读写、
    执行命令。→ 不要在不受信任的网络里开着它；不用时关掉。
  - ~/.cc-web\ 下的会话记录、~/.claude\settings.json（含密钥）不要互相拷贝、不要外传。


【11】常见坑（都实际踩过）
--------------------------------------------------------------------------------
  - 一定要走 start.bat（理由见【5】）。
  - java_compiler_mcp 文件夹要整体拷，exe 与 _internal 必须保持同级。
  - 分发包里的服务器地址是编译进 exe 的，要改地址必须重新编译（找管理员）。
  - skill 目录不要套多一层：应为 skills\java-compiler-mcp\SKILL.md。
  - 本机 ~/.claude.json 里已有的 MCP 会一起加载，属正常现象。
  - cc-web 是“每条消息起一个 claude 进程”，所以首次响应会略慢，属正常。
